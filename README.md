Estructura del proyecto
menu.js= se muestra el array(objeto) principal para poder inicial con el modelo restaurante y usas sus propiedades para el 
sistema
index.html=se muestra la esctructura y la parte visual del funcionamiento de la web y de la interaccion con el usuario para 
acceder al sistema
operaciones.js=en este archivo se muestra las operaciones del sistema como buscar filtrar encontrar operaciones que no has ayuda con los botones hacer eventos para hacer las tareas que se piden para el sistema la parte logica
ui.js=donde se dara acccion a las operaciones y todo lo que se mostrara en pantalla como alertas o los menus en el sistema
